# Implementation Plan

## Overview

این برنامه‌ی اجرایی، بهبود و آماده‌سازی پروژه برای ارائه‌ی دانشگاهی را به تسک‌های کوچک و کم‌ریسک تقسیم می‌کند: سلامت‌سنجی، پاک‌سازی کد، اصلاح باگ‌های روشن، امنیت محیطی، غنی‌سازی داده، مستندسازی و تأیید نهایی. تسک‌ها به‌ترتیب وابستگی اجرا می‌شوند تا در هیچ نقطه‌ای پروژه خراب نماند.

## Tasks

- [x] 1. سلامت‌سنجی اولیه و نقشه‌برداری وابستگی‌ها

  - گرفتن گزارش از همه‌ی `print`های دیباگ و فایل‌های مشکوک به کد مرده با grep.
  - تأیید اینکه `src/power_source/` در هیچ ماژول فعالی import نشده.
  - ثبت وضعیت پایه برای مقایسه‌ی بعد از تغییرات.
  - _Requirements: 1.1, 1.4, 4.1, 4.6_

- [ ] 2. پاک‌سازی کد مرده و فایل‌های اضافی

  - _Requirements: 4.1, 4.6_

  - حذف بلوک بزرگ کد کامنت‌شده‌ی SQLAlchemy در `order/services.py` و `db/db.py`.
