# دانشگاه آزاد اسلامی واحد پردیس

سامانه‌ی مدیریت ریزشبکه‌ی برق مستقیم (DC Micro-grid) و انرژی خورشیدی. این پروژه یک پلتفرم کامل برای مدیریت پنل‌های خورشیدی، باتری‌ها، مصرف برق ساختمان‌ها و فروشگاه آنلاین است که به عنوان پروژه‌ی دانشگاهی برای **دانشگاه آزاد اسلامی واحد پردیس** توسعه داده شده است.

## معرفی پروژه

این سامانه برای محاسبه، پایش و مدیریت تولید و مصرف انرژی در یک ریزشبکه‌ی برق مستقیم طراحی شده است. کاربران می‌توانند پنل‌های خورشیدی، باتری‌ها و دستگاه‌های مصرف‌کننده‌ی برق خود را ثبت کنند و میزان تولید، ذخیره و فروش انرژی را مدیریت کنند. علاوه بر این، بخش فروشگاه و پرداخت آنلاین (از طریق درگاه زرین‌پال) نیز در پروژه پیاده‌سازی شده است.

## امکانات اصلی

- **احراز هویت کاربران**: ثبت‌نام با کد یک‌بارمصرف (OTP)، ورود، بازیابی رمز عبور و ورود از طریق حساب گوگل (SSO).
- **مدیریت پنل خورشیدی**: ثبت و مدیریت پنل‌های خورشیدی به همراه ظرفیت بیشینه، ظرفیت ذخیره‌شده و ظرفیت فروخته‌شده.
- **مدیریت باتری و دستگاه‌ها**: ثبت دستگاه‌های مصرف‌کننده‌ی برق با مصرف AC و DC.
- **مدیریت آپارتمان و بلوک**: ساختاردهی مصرف انرژی بر اساس واحدها و بلوک‌های ساختمانی.
- **ثبت رکوردهای مصرف برق**: ثبت زمان شروع، پایان و میزان انرژی مصرف‌شده.
- **قیمت‌گذاری و سفارش‌ها**: مدیریت قیمت‌ها، سبد خرید و ثبت سفارش.
- **پرداخت آنلاین**: اتصال به درگاه پرداخت زرین‌پال.
- **پنل مدیریت**: مدیریت کاربران، مجوزها و محتوای سامانه توسط ادمین.
- **رابط کاربری چندزبانه**: پشتیبانی از فارسی و انگلیسی با طراحی واکنش‌گرا.

## معماری و تکنولوژی‌ها

سامانه از دو بخش بک‌اند و فرانت‌اند تشکیل شده که به‌صورت کانتینری با Docker اجرا می‌شوند:

| بخش | تکنولوژی |
|------|-----------|
| بک‌اند | Python ۳.۱۱ + FastAPI |
| پایگاه داده | MongoDB |
| کش و صف | Redis |
| فرانت‌اند | Nuxt 3 (Vue) + Tailwind CSS |
| پرداخت | درگاه زرین‌پال |
| ذخیره‌سازی فایل | Object Storage سازگار با S3 (ArvanCloud) |
| اجرا | Docker و Docker Compose |

## ساختار پروژه

<div dir="ltr">

```
University-Project/
├── docker-compose.yml          # تعریف سرویس‌ها (بک‌اند، فرانت، دیتابیس، ردیس)
├── .env.example                # نمونه‌ی متغیرهای محیطی
└── university-project/
    ├── back/                   # بک‌اند FastAPI
    │   ├── Dockerfile
    │   └── src/
    │       ├── main.py         # نقطه‌ی شروع برنامه
    │       ├── auth/           # احراز هویت و کاربران
    │       ├── solar_panel/    # پنل‌های خورشیدی
    │       ├── battery/        # باتری‌ها
    │       ├── device/         # دستگاه‌ها
    │       ├── apartment/      # آپارتمان‌ها
    │       ├── block/          # بلوک‌ها
    │       ├── power_record/   # رکوردهای مصرف برق
    │       ├── power_source/   # منابع برق
    │       ├── pricing/        # قیمت‌گذاری
    │       ├── order/          # سفارش‌ها و پرداخت
    │       ├── profile/        # پروفایل کاربران
    │       ├── admins/         # مدیریت
    │       ├── core/           # ابزارها و مدل‌های پایه
    │       └── db/             # اتصال به پایگاه داده
    └── front/                  # فرانت‌اند Nuxt
```

</div>

## راه‌اندازی پروژه

۱. فایل‌های متغیر محیطی را از روی نمونه‌ها بسازید:

<div dir="ltr">

```bash
cp .env.example .env
cp university-project/front/.app/.env.example university-project/front/.app/.env
```

</div>

۲. کل سامانه را با Docker Compose اجرا کنید:

<div dir="ltr">

```bash
docker compose up --build
```

</div>

۳. پس از بالا آمدن سرویس‌ها، برای ساخت کالکشن‌های اولیه‌ی پایگاه داده یک‌بار آدرس زیر را باز کنید:

<div dir="ltr">

```
http://localhost:8002/startup
```

</div>

## دسترسی به سرویس‌ها

| سرویس | آدرس |
|--------|------|
| فرانت‌اند (وب‌سایت) | http://localhost:80 |
| بک‌اند (API) | http://localhost:8002 |
| مستندات API (Swagger) | http://localhost:8002/docs |
| پنل مدیریت دیتابیس (Mongo Express) | http://localhost:8082 |

## متغیرهای محیطی

مهم‌ترین متغیرهای محیطی در فایل `.env` (نمونه در `.env.example`):

- `DATABASE_URL`: آدرس اتصال به پایگاه داده‌ی MongoDB
- `SECRET_KEY` و `ALGORITHM`: تنظیمات توکن و احراز هویت
- `SMTP_*`: تنظیمات ارسال ایمیل
- `MERCHANT` و `ZP_API_*`: تنظیمات درگاه پرداخت زرین‌پال
- `AWS_*`: تنظیمات فضای ذخیره‌سازی فایل (سازگار با S3)
- `FRONTEND_SERVER_URL`: آدرس فرانت‌اند

## نکات امنیتی

> ⚠️ فایل `.env.example` صرفاً نمونه است. **هرگز** کلیدها و رمزهای واقعی را در مخزن گیت قرار ندهید. پیش از استقرار در محیط واقعی، تمام مقادیر حساس (مانند `SECRET_KEY`، رمز SMTP، کلیدهای پرداخت و کلیدهای S3) را با مقادیر جدید و امن جایگزین کنید.
